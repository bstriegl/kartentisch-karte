# Kartentisch – Topokarte

Kartenansicht zum Kartentisch (Lesebegleiter für Sachtexte). Die Seite zeigt die Orte eines Kapitels auf einer topografischen Karte.

Die Orte stehen im Link selbst (hinter dem `#`). Die Seite speichert nichts und sendet die Orte nirgendwohin; geladen werden nur die Kartenkacheln des gewählten Kartendienstes.

Karten: OpenTopoMap, OpenStreetMap, Kartverket (Norwegen). Kartenbibliothek: Leaflet.
